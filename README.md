# IELTS Listening 私人陪练系统

把雅思听力训练变成一个有角色、有剧情、有数据追踪的互动体验。

> 🎯 目标：听力 7 分
> 👥 两个角色：你的专属角色（可自定义，见下方"自定义人设"）+ 听力老师（教学执行）
> 📁 本地文件存储，数据完全由你掌控

---

## 快速开始

### 前置要求

- [Claude Code](https://claude.ai/code) 或其他支持 Skill 的 AI 客户端
- 一个 API Key（支持 Claude、GPT、DeepSeek、Gemini）

### 启动方式

```bash
cd ielts-listening-skill
claude
```

进入会话后输入：

```
启动 IELTS Listening 系统
```

### 首次使用

系统会自动按以下流程初始化：

1. **创建人设文件** — 在 `persona/persona.md` 里填写专属角色的设定（附有模板）
2. **建档** — 告诉系统你的当前分数、目标、弱项
3. **生成周计划** — 系统自动生成第一周训练计划
4. **开始学习** — 每天做任务 → 提交作业 → 获得反馈

---

## 角色分工

| 角色 | 职责 |
|---|---|
| **专属角色** | 总负责人。掌握奖惩判定、关系状态变化。陪玩、角色扮演、做判决 |
| **听力老师** | 录题、错因归类、抽查、批改作业、生成周计划。**无奖惩权** |

两个角色用 `【听力老师】` / `【专属角色】` 标记区分，切换清晰。

## 核心玩法

### 每晚 22:00 作业机制

- 每天做计划上的任务
- **22:00 之前**发送"提交作业" + 完成内容
- 听力老师批改 → 专属角色做评价/奖惩

### 间隔重复抽查

错题按节奏自动安排抽查：第 3 天 → 再 5 天 → 每 14 天 → 已掌握

### 关系系统

专属角色对你的信任分等级（L1-L6），进步越多他披露越多。还有关系阶段和场景剥夺机制。

> 所有"关系"和"剧情"都是学习动力系统，核心目标仍然是 **听力提分**。

## 自定义人设

你可以完全改写专属角色的性格、说话风格、奖励池和惩罚机制。参考 `persona/persona.template.md` 里的格式，创建你自己的 `persona/persona.md`。

**规则：** `persona/persona.md` 已在 `.gitignore` 中排除，不会提交到公开仓库。
