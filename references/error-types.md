# 错因分类法 v2

雅思听力错题归因为**七类**(原五类 + 拼写 + 题干预读)。归类的目的是**对症下药**。

---

## 一、词义(Meaning)
**定义**:听到了那个词,但不知道它的中文意思,所以填不对、选不对。

**典型表现**:
- 听完能复述出那个单词,但要写答案时不知道写什么
- 看到答案恍然大悟:"哦原来是这个意思"

**抽查方式**:中译英 / 英译中 / 用这个词造句

**典型高发陷阱**:
- assumption(S3-26 错过)
- salt(S4-38 错过,基础词不熟)

---

## 二、读音(Pronunciation)
**定义**:这个单词其实认识、知道意思,但听到的时候没反应过来 / 听成了别的。

**典型表现**:
- 看到答案后:"这个词我认识啊!怎么没听出来?"
- 把 thirty 听成 thirteen
- 连读、弱读吃掉了关键音
- 元音长短分不清(ship / sheep)

**抽查方式**:给音标 → 用户拼写 / 给词 → 用户描述发音

**典型高发陷阱**:
- 缩读:as we'd / there'd / it's / I'll / won't / we've
- 弱读:of / for / from / to 在句中的真实发音

---

## 三、搭配(Collocation)
**定义**:单词都认识,意思也懂,但组合起来不会用 / 介词错了 / 词形错了。

**典型表现**:
- 听到 "make a decision",写成 "do a decision"
- 听到 "in the morning",写成 "on the morning"
- 单复数错(听到 "two children" 写成 "two child")

**抽查方式**:挖空填空 / 中译搭配

---

## 四、同义替换(Paraphrasing)
**定义**:题目里写的词和录音里说的词不一样,但其实是一个意思——没听出这层换皮关系。

**典型表现**:
- 题目问 "the main reason",录音说 "the most important factor"
- 选择题里所有选项都"看似有道理",但只有一个是真正同义替换

**这是 6 分到 7 分的核心难点。**

**抽查方式**:给原句让用户说出题目同替 / 给考点词让用户列同替

**典型高发陷阱**(诊断案例):
- attention to ↔ takes care with
- areas with heavy traffic ↔ busy roads(especially 信号词)
- made of (metal) ↔ a metal instrument known as

---

## 五、拼写(Spelling)— 常见核心病灶
**定义**:听对了、意思也对,但因为拼写错丢分。

**典型表现**(诊断案例):
- diary(单复数:diaries)
- tidy(过去式:tidied)
- graphics(单复数都加 s)

**这是最容易拿回的分(诊断显示占错题 17%)。**

**抽查方式**:听音 / 看中文,在纸上手写英文。错一个抄 5 遍,第二天复测。

**易错词类**(优先训练):
- **双辅音词**:accommodation / committee / professional / occurred
- **以 -y 结尾**:diary→diaries / tidy→tidied / company→companies
- **不发音字母**:receipt / Wednesday / restaurant / vegetable
- **ie / ei**:receive / believe / achieve / weight
- **复合词带连字符**:part-time / well-known / check-in
- **同音不同形**:weather/whether, their/there, principal/principle

---

## 六、题干预读(Pre-reading)— 常见核心病灶
**定义**:做题时没有提前预读题干,导致听的时候不知道在找什么。

**典型表现**(诊断案例):
- "只听到了 oil,没有去理解题目"(S4-33)
- "不理解题干,没有预判,不知道要找什么单词"(S4-35)

**抽查方式**:给题干 → 让用户说出
1. 该填什么词性
2. 该填什么语义类型(地点 / 颜色 / 数量 / 时间 / 材料 / 方式 / ...)
3. 可能的同义替换方向

---

## 七、其他(Mechanical errors)
**定义**:听对了、意思也对,但机械性错误。

**典型类型**:
- 大小写错(专有名词没大写)
- 超字数(题目要求 NO MORE THAN TWO WORDS,写了三个)
- 答案位置错(把第 5 题的答案写到第 6 题位置)

**抽查方式**:听写专项 / 复盘是否养成不良习惯

---

## 八、归类的灰色地带

有时候一道错题可能跨多类。归类原则:
- **听到了但不认识 → 词义优先**
- **听到的发音和印象中不同 → 读音优先**
- **听对了所有词但意义没对应上题目 → 同义替换**
- **听对+理解对+答案对,但拼写错 → 拼写**
- **题干没读懂导致听的时候没目标 → 题干预读**

如果实在拿不准,让用户自己说"主要是因为什么没做对",按用户主观判断归类。

---

## 九、错因占比的诊断意义

每月生成进度报告时,统计错因占比。不同分布对应不同诊断:

| 主要错因 | 诊断 | 改进方向 |
|---|---|---|
| 词义占比高 | 词汇量不足 | 攻同桌 / 场景词 |
| 读音占比高 | 听辨能力弱 | 精听 + 跟读 |
| 搭配占比高 | 语言运用基础弱 | 补语法 + 多读地道材料 |
| 同义替换占比高 | 6→7 瓶颈 | 刘洪波 179 + 何琼必考改写 |
| **拼写占比高** | **习惯问题,容易解决** | **每晚拼写自测专项** |
| **题干预读占比高** | **方法论问题** | **强制预读训练 1 周** |
| 其他占比高 | 习惯问题 | 听写专项 + 强化做题规范 |

---

## 十、诊断的错因分布(基线示例)

来自诊断套题分析:

| 错因 | 占比 | 改进可能性 |
|---|---|---|
| 同义替换 | 28% | 中(2-3 周训练) |
| 读音(缩读为主) | 22% | 中(精听+跟读) |
| 拼写 | 17% | **高(3-5 天)** |
| 词义(中级词) | 17% | 中 |
| 题干预读 | 11% | **高(1 周)** |

**目标**:23 天后,拼写 + 题干预读两项错题占比降到 < 5%(几乎消除)。
