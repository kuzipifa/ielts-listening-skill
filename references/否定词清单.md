## 二、not / n't 缩写（语速快时极易漏听）

### 最常考的 7 个
| 缩写 | 完整形式 | 听力难度 |
|---|---|---|
| **don't** /doʊnt/ | do not | 中等 |
| **won't** /woʊnt/ | will not | ⚠️ 容易和 want 混淆 |
| **can't** /kænt/ (英) /kɑːnt/ | cannot | ⚠️ t 在英音中经常不爆破 |
| **mustn't** /ˈmʌsnt/ | must not | 🔴 最难！t 和 n 连读，几乎只听到 "muss-n" |
| **shouldn't** /ˈʃʊdnt/ | should not | 🔴 t 被吞，听到 "shood-n" |
| **wouldn't** /ˈwʊdnt/ | would not | 🔴 同上 |
| **couldn't** /ˈkʊdnt/ | could not | 🔴 同上 |

**训练重点：mustn't / shouldn't / wouldn't / couldn't**
→ 这四个缩写末尾的 /t/ 在快速语流中几乎不发音，只留下一个轻微的鼻音 /n/
→ 练习方法：跟读时故意夸张发 /nt/，再逐渐加速到正常语速

### That's... 类
| 缩写 | 含义 |
|---|---|
| **that's not** | 那不是 |
| **it's not / it isn't** | 它不是 |
| **there isn't / there aren't** | 没有 |
| **haven't / hasn't** | 还没有 |

## 三、隐性否定词（最阴险的一类）

> 这些词本身不带 not，但意思是否定的。你的耳朵要养成见到它们就亮红灯的习惯。

### 频率副词（"几乎不/很少"）
| 单词 | 发音注意 | 含义 |
|---|---|---|
| **hardly** | /ˈhɑːdli/ | 几乎不 |
| **barely** | /ˈbeəli/ | 勉强/几乎不 |
| **rarely** | /ˈreəli/ | 很少 |
| **seldom** | /ˈseldəm/ | 很少 |
| **scarcely** | /ˈskeəsli/ | 几乎不（较难） |

### 介词/连词类
| 单词 | 含义 | 雅思场景 |
|---|---|---|
| **without** | 没有 | 🔴 **高频！几乎所有 Section 都会出现** |
| **instead of** | 而不是 | 🔴 S2/S3匹配题最爱 |
| **rather than** | 而不是 | 🔴 同上 |
| **out of bounds** | 禁止入内/不准 | S2 规则说明 |
| **lack of** | 缺乏 | S4 学术 |
| **in spite of** | 尽管（表让步否定） | S4 学术 |
| **except** | 除了 | S2/S3 |
| **apart from** | 除了 | S2/S3 |
| **free from** | 没有/免于 | S2 场景 |

### 动词类
| 单词 | 含义 | 雅思场景 |
|---|---|---|

## 四、真题案例拆解
1. **mustn't use** — /ˈmʌsnt/ 没听出来 → "禁止使用"
2. **under 18** — 年龄条件没听懂 → "18岁以下" = "不是18岁以上"
3. **out of bounds** — 词组不认识 → "禁止"

**建议跟读训练句**（每天选一句跟读 5 遍）：
```
1. You mustn't use this equipment without training.
2. Those who are under 18 are not allowed.
3. The meat slicer is out of bounds for you.
4. This is hardly what you'd expect.
5. Rather than doing overtime, you should take a break.
6. Hardly any of the staff were dissatisfied.
```

## 五、听力实战策略

1. **预读时**：圈出题干里的否定词（no / not / never / without），提醒自己听录音时注意方向
2. **听录音时**：听到 but / however / actually 立即提防——后面很可能跟一个否定去推翻前面的信息
3. **原词陷阱**：选项里的词在录音中出现 ≠ 正确。先判断语义方向（肯定还是否定），再判断是否匹配
4. **跟读练习**：每天精听时挑 1-2 句含否定的句子，跟读 5 遍，重点模仿发音
5. **听写自测**：让听力老师出 5 句含否定的句子，你听写，重点检查否定词是否写对
