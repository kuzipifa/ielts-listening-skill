# 周计划生成规则

## 一、生成时机

- **每周日 20:00 之后**听力老师自动生成下周计划
- 计划写入 `data/计划-第N周.md`(N = 第几周,从 1 开始)
- 用户确认/调整后开始执行

## 二、23 天三阶段总览(示例时间线)

### 阶段一:打地基(第 1 周,4.28-5.4)
- **核心目标**:消除白丢分(拼写 + 题干预读)+ 启动同义替换专项
- **核心任务**:每天 1 套完整 4-Section 听力(不许跳)+ 拼写专项 + 刘洪波 179 + 题干预读训练
- **新错题率**:每天预计录入 5-10 道
- **进度指标**:周末抽查通过率 60%+,拼写错率 <30%

### 阶段二:攻题型(第 2 周,5.5-5.11)
- **核心目标**:匹配题专项 + 地图题专项 + 缩读听辨
- **核心任务**:重练剑 16(分数最低)+ 补做剑 19 S2/S3(之前主动跳过的)+ 缩读跟读
- **进度指标**:周末抽查通过率 70%+,匹配题正确率提升

### 阶段三:冲刺模考(第 3 周,5.12-5.17)
- **核心目标**:全套模考 + 心理调节 + 错题复盘
- **核心任务**:剑 20 + 剑 14(从未做过的新题)按完整考试流程模考
- **考前一天**:只做错题复习,不做新题,看 1 页方法论清单
- **考试日上午**:休息,不学习

## 三、每日任务模板

### 任务结构(每天)
```
今日核心任务 ⭐(必须 100% 完成)
  └─ 1 项,通常是完整套题或重要专项

今日常规任务(完成 80% 即合格)
  ├─ 任务 A
  ├─ 任务 B
  └─ 任务 C(3-5 项)

每日固定项(每天必有,不计入任务数)
  ├─ 刘洪波 179 当日 20 个词
  ├─ 同桌答案词(高频)当日 10 个
  ├─ 拼写自测 10 词(听力老师晚上 22:00 出)
  └─ 系统抽查(若今天有该抽的错题)
```

### 时长估算
- 核心任务:90-120 分钟
- 常规任务:总计 60-90 分钟
- 固定项:60-80 分钟
- **每日总投入:3.5-5 小时**(根据用户实际情况调整)

## 五、周计划生成原则(给听力老师)

### 任务安排原则
1. **核心任务每天必须有,且不许是"复习"** — 必须是新做或新练
2. **S2/S3 出现频率 ≥ 60%** — 治回避弱项的病
3. **同义替换训练每天必有**(刘洪波 179 / 何琼必考改写)
4. **拼写训练每天必有**(每晚 22:00 自测)
5. **题干预读训练阶段一每天必有**
6. **每周必有至少 2 套完整 4-Section 套题**(不许拆做)

### 任务分配到周(阶段一示例)
- 周一:剑 14 Test 2 全套 ⭐ + 同义替换专项
- 周二:精听昨天 S2/S3 段落 ⭐ + 题干预读训练
- 周三:剑 14 Test 3 全套 ⭐ + 错题复习
- 周四:精听 + 缩读跟读 ⭐ + 拼写补漏
- 周五:剑 13 Test 1 全套 ⭐ + 同义替换复盘
- 周六:**休息日**(英文汇报 + 闲聊)
- 周日:本周错题大复盘 ⭐ + 下周计划生成

## 六、周内调整规则

### 申请调整流程
1. 用户用**英文写 50 词理由**,发给 Noah
2. Noah 批改语法
3. Noah 决定是否同意:
   - 真正的不可抗力(生病、突发要事)→ 同意
   - 单纯不想做 / 累 / 状态差 → 拒绝
4. 同意:听力老师把任务挪到周末加倍
5. 拒绝:维持原计划,且当天必须完成

### 限制
- **每周最多调一次**
- 第二次申请 = 自动拒绝
- 周六请假不算调整(本来就是休息日)

## 七、阶段进度评估(每周日生成)

每周日生成下周计划之前,听力老师生成本周回顾:

```
第 N 周回顾(YYYY-MM-DD ~ YYYY-MM-DD)

完成情况:
- 计划任务总数:X 项
- 实际完成:Y 项
- 完成率:X%
- 核心任务完成率:X%
- 22:00 准时交作业:X / 7 天

学习数据:
- 新增错题:X 道
- 抽查通过率:X%
- 拼写自测通过率:X%

分数动向:
- 本周做题数:X 套
- 平均分:X / 40
- 较上周变化:+/- X 分

诊断报告对比:
- 五大病灶各项错题占比变化
- 哪个病灶进展最大
- 哪个病灶仍是瓶颈
```

这份回顾给 Noah 做下周判决和奖惩调整的依据。
